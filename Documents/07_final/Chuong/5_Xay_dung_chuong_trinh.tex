\section{Công nghệ sử dụng}
Hệ thống NaviMart được xây dựng dựa trên các công nghệ và thư viện hiện đại nhằm tối ưu hóa hiệu suất và trải nghiệm người dùng:
\begin{itemize}
    \item \textbf{Backend \& Real-time:}
    \begin{itemize}
        \item Nền tảng: Node.js
        \item Framework: NestJS (xây dựng RESTful APIs)
        \item Giao tiếp thời gian thực: Socket.io
    \end{itemize}
    \item \textbf{Cơ sở dữ liệu (Database):}
    \begin{itemize}
        \item Hệ quản trị CSDL: MongoDB
        \item Thư viện tương tác: Mongoose
    \end{itemize}
    \item \textbf{Bảo mật \& Xác thực (Security \& Auth):}
    \begin{itemize}
        \item JSON Web Token (JWT)
        \item Passport (Local \& JWT Strategy)
        \item Mã hóa mật khẩu: Bcrypt
    \end{itemize}
    \item \textbf{Frontend (Client):}
    \begin{itemize}
        \item Thư viện cốt lõi: React (sử dụng TypeScript)
        \item Quản lý giao diện \& Styling: TailwindCSS
        \item Quản lý định tuyến: React Router DOM
        \item Build tool: Vite
    \end{itemize}
    \item \textbf{Lưu trữ đám mây (Cloud Storage):}
    \begin{itemize}
        \item Lưu trữ hình ảnh: Cloudinary
    \end{itemize}
\end{itemize}
